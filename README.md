
# ❤️ Heart Failure Data Visualization

## 📊 Overview

This project explores the Heart Failure dataset using **Python, Pandas, Matplotlib, and Seaborn**. The goal is to **analyze patterns between patient features and survival outcomes**.

---

## 🗂 Dataset

Contains clinical data including:

* 👤 Age, sex
* 💉 Blood pressure, ejection fraction, serum sodium & creatinine, platelets, CPK
* ⚕️ Health conditions: anemia, diabetes, smoking, high blood pressure
* 🎯 Target: `DEATH_EVENT` (0 = Survived, 1 = Died)

---

## 📈 Visualizations

* **Pairplots:** Numeric variables with KDE diagonals, colored by survival status
* **FacetGrid Scatterplots:** Explore numeric relationships by categorical variables
* **Violin & Boxplots:** Compare distributions across categories
* **Histograms & KDEs:** Show distributions of lab values for survival groups
